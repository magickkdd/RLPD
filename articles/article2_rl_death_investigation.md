# 强化学习训练"猝死"排查实录：从 15/15 全灭到 12/12 达标

> 这是一次持续 4 天的排障实录：RLPD 强化学习复现中，15 个训练 run 全部在早期"猝死"——策略先冲到 95+ 分，然后骤降为恒定 0 分直到训练结束。数据没问题、代码与官方逐行一致、无 NaN、无并发干扰……最终根因藏在一个**第三方库的隐式缓存语义**里。本文完整还原诊断链，希望这套方法论能帮你省下几天时间。

## 一、症状：不是学不会，是学得很好然后猝死

复现 RLPD（ICML 2023）时，我们在 AMD MI300X 上跑 4 个 D4RL 任务 × 3 seeds。第一轮训练"完成"后终评，12 个 run 的分数全是 **-2.57 分左右的垃圾策略**——与训练日志里 92-99 分的评估完全矛盾。

训练曲线揭示了更诡异的画像：

```
hopper s43:   @15000 = 43.9 → @20000 = 20.4 → @25000 起恒定 0.7（直到 200k 结束）
walker2d s42: @25000 = 99.8 → @30000 骤降至 1.5（恒定到 200k 结束）
```

**不是学不会，是学得很好然后猝死**。且死亡分数高度一致（0.0 / -0.026 / 0.7 / 1.8），跨 4 个环境、跨 3 个 seed。

## 二、逐项排除：每个"显然的嫌疑人"都是清白的

### 2.1 数据集验尸（无罪）

用 h5py 直接解剖 5 个 D4RL 数据集：轨迹 return 分布、reward 均值/最大值、terminal 比例，全部符合官方画像（hopper-expert 轨迹均值 norm=108.5、walker2d-expert 107.1）。数据无罪。

### 2.2 代码审查（无罪）

RLPD 的 update 主循环、UTD 切片、terminal mask（`1 - termination`，`TimeLimit.truncated` 不算真终止）、LayerNorm 位置、ensemble min 逻辑——与官方实现逐行对齐。config（num_qs=10、num_min_qs=2、critic_layer_norm=True）全对。

### 2.3 GPU 风暴与断点续训（无罪）

死亡时间精确反推：全部发生在实例**干净连续训练段**，早于已知的 GPU 初始化风暴窗口；续训链路经 checkpoint restore 叶级对拍（36 条参数路径零差异）排除。

### 2.4 ckpt 健康筛查（里程碑式的误导）

我们对 12 个 run 的所有留存 ckpt 做了分数筛查——结论"11/12 在 105k~200k 全窗口死亡"一度让排查方向跑偏。**教训：筛查结论要和训练曲线交叉验证**。曲线显示死亡远早于 ckpt 窗口下限——50k 以下的 ckpt 早已被 keep=20 滚动删除，"全窗口死亡"只说明"死亡点之前的物证已被销毁"。

## 三、决定性证据：q 曲线与参数验尸

### 3.1 参数验尸

加载死亡 ckpt 与健康 ckpt 对比参数统计：

| agent | actor 范数 | critic 范数 | \|log_alpha\| |
|---|---|---|---|
| FRESH 基线 | **17.0** | 89.3 | 0 |
| hopper s42@150k（死） | **3117** | 1321 | 1.5 |
| walker2d s42@150k（死） | **1761** | 313 | 2.2 |
| halfcheetah s42@150k（活） | **57.2** | 675 | 0.35 |

画像：**actor 参数爆炸 100~180 倍、critic 相对正常、零 NaN**。这不是数值损坏，是训练动力学病理：actor 被某种无限大的梯度推着走。

### 3.2 q 曲线（wandb 离线文件的字节级解析）

wandb 0.30 移除了 Python 解析 API，我们写了锚点字节扫描器直接读 protobuf 裸流，提取出训练全程的 q 值与熵曲线——**猝死现场全程录像**：

```
hopper s43:
@20000  q = 308.6   entropy = -1.23      ← 一切正常
@20995  q = 1007.7  entropy = +8.5e23    ← q 突跳 3.3 倍，熵天文数字！
@22000+ q 恒定 1007  entropy 指数爆到 3.2e24
```

链条闭合：

```
critic 过估计突跳 → actor 追逐坏 Q → μ 爆炸（参数范数 ×100）
→ σ 触底时 log_prob 溢出 → entropy = -log π 爆到 1e24
→ 温度 α 梯度爆炸 → α 崩塌 → 熵正则消失
→ 纯贪心策略 → 恒定饱和动作 → 恒定 ~0 分
```

## 四、根因：tfp 的隐式缓存语义

actor 输出 tanh-normal 分布。原实现用 tensorflow-probability，我们因 JAX 0.8 兼容性用 ~70 行纯 JAX 自实现替代。数学公式完全正确，数值对拍（正常区）完全通过——**但我们漏了 tfp 文档里没写的隐式行为**：

**tfp 的 `TransformedDistribution` 在同一对象上先 `sample()` 再 `log_prob(采样值)` 时，会复用 sample 阶段缓存的中间量 y（精确值），而不是从 x 反推。**

RLPD 的代码恰好就是这个调用模式：

```python
actions = dist.sample(seed=key)      # 内部缓存了 y = mu + sigma * eps
log_probs = dist.log_prob(actions)   # tfp: 用缓存的 y；我们: atanh(clip(x)) 反推
```

两条路径在正常区数值一致（所以我们的对拍通过了！），但在**饱和区**（σ 被 clip 到下限 e^-20 ≈ 2e-9、且 μ 偏离）分道扬镳：

| 路径 | log_prob | 梯度范数 |
|---|---|---|
| tfp 缓存语义（精确 y） | 83 ~ 653 | 恒定 3.87 |
| 我们的 atanh(clip(x)) 反推 | **-1.9e10 ~ -3e21** | **2e10 ~ inf** |

机理：y 被 atanh+clip 压在 ±7.25 附近，而 μ 可以是 ±千级（actor 爆炸后）→ z=(y−μ)/σ 的分母是 2e-9 → z² ~ 1e19 → f32 溢出。而 clip 的梯度在触界处为 0，熵项的梯度信号整体断流。

**修复 = 复刻缓存语义**（sample 时缓存 y，log_prob 检测到采样值即走精确路径）。修复后饱和区 log_prob = 85.25（健康），训练再也不猝死。

## 五、第二只拦路虎：130k 死亡窗

修复后重跑，又发现新规律：**从 0 起跑的训练 run 全部在第 126~131k 步 segfault（11/11，跨 4 env 跨 seed），而从 @125k checkpoint 续训的 run 稳定存活（2/2）**。触发机制至今未明（JAX 0.8/ROCm 栈内的长运行累积问题），但统计边界足够清晰。

我们的对策是**两段式绕窗**：每个 run 拆成 `0→125k` 停车 + `ckpt 续训→目标`——第一段在窗口前刹车，第二段的等效步数只有 75k/125k，整个窗口被结构性跳过。

**这里有个工程判断值得强调**：机制未明 ≠ 无法推进。当"不绕窗 = 100% 死亡、绕窗 = 零代价"时，经验对策就是正确的第一步，根因研究可以并行。

## 六、结果

两段式 + 修复版代码，跨 5 台实例（平台多次关机/挂起，ckpt 断点续训全程兜底）：

| 任务 | 终评（100 episodes）3 seeds | 均值 |
|---|---|---|
| halfcheetah-expert | 99.44 / 95.88 / 104.08 | **99.80** |
| hopper-expert | 92.72 / 113.23 / 91.74 | **99.23** |
| walker2d-expert | 130.06 / 126.04 / 131.48 | **129.19** |
| walker2d-medium-replay | 120.19 / 120.43 / 126.72 | **122.45** |

**12/12 全部 ≥ 90 分，零策略死亡。**

## 七、可复用的方法论

1. **筛查结论必须与训练曲线交叉验证**——物证（ckpt）可能已被滚动删除，幸存的证据会误导方向。
2. **参数验尸是 RL 排障的利器**：actor/critic 分开看范数，|log_alpha| 单独看——"谁爆炸了"直接指向病灶模块。
3. **wandb 离线文件是宝库**：0.30 移除了解析 API，但 protobuf 裸流的锚点字节扫描可以恢复全部指标（q、entropy、loss）——时间序列证据比任何猜测都硬。
4. **对拍必须覆盖退化/饱和边界**：正常区一致 ≠ 等价；第三方库的隐式状态语义（缓存、懒初始化、全局状态）是替代实现的最大盲区。
5. **猝死指纹**：先冲高分后骤降恒定 ~0 分 + entropy > 1e10 → 优先查分布实现的数值路径，而不是并发、硬件或数据。
